# Detox

**Detox** – это приложение для управления рабочими перерывами, созданное для повышения продуктивности и снижения нагрузки на глаза. Программа автоматически напоминает пользователям делать короткие и длинные перерывы, а также предоставляет гибкие настройки времени и режима работы.

## 🔹 Основные функции

✅ **Гибкие напоминания** – настройка частоты и длительности перерывов.  
✅ **Режим полного экрана** – возможность блокировки экрана во время перерыва.  
✅ **Анимированные визуальные элементы** – приятный интерфейс с плавной анимацией.  
✅ **Статистика** – отслеживание количества и продолжительности перерывов.  
✅ **Поддержка трея** – сворачивание программы в трей для удобства.  
✅ **Звуковые уведомления** – активация аудио-сигналов для уведомлений.  

## 🛠 Технологии

- **Язык:** Python  
- **Библиотеки:** Tkinter (ttkbootstrap), Pystray, Pillow, JSON  
- **Графический интерфейс:** ttkbootstrap  
- **Поддержка трея:** Pystray
